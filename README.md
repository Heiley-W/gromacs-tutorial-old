# GROMACS Tutorials

This repository contains a collection of tutorials for simulating molecular dynamics using GROMACS (GROningen MAchine for Chemical Simulations). The step-by-step instructions and explanations can be found in the respective Jupyter Notebooks.

## Tutorials

1. **Tutorial 1 - Lysozyme in Water**
- Source: [Lysozyme in Water Tutorial](http://www.mdtutorials.com/gmx/lysozyme/index.html)
- Jupyter Notebook Location: `tutorial-1/tutorial-1.ipynb`
- Description: This tutorial guides new users through the process of setting up a simulation system containing the protein lysozyme in a box of water, along with ions. It includes explanations of both input and output settings, utilizing typical configurations for general use.

2. **Tutorial 2 - Introduction to Membrane-Protein Simulation**
- Source: [Membrane-Protein Simulation Tutorial](https://tutorials.gromacs.org/membrane-protein.html)
- Jupyter Notebook Location: `tutorial-2/tutorial-2.ipynb`
- Description: This tutorial provides a step-by-step approach to running a molecular dynamics simulation of a simple membrane protein using GROMACS. It covers the setup of input files and the entire process from energy minimization to data production.

3. **Tutorial 3 - Free Energy of Solvation**
- Source**: [Free Energy of Solvation Tutorial](https://tutorials.gromacs.org/docs/free-energy-of-solvation.html)
- Jupyter Notebook Location: `tutorial-3/tutorial-3.ipynb`
- Description: This tutorial teaches users how to calculate the solvation free energy for a small solute using alchemical transformation and the Bennett Acceptance Ratio (BAR) method. It includes practical tips for executing the calculations in GROMACS.
